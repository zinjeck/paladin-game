# Branch scope

`migration/godot-4.7.1` is an engine-only migration branch.

Allowed changes:
- Godot project metadata required by 4.7.1.
- CI engine pinning.
- Compatibility repairs required for Godot 4.7.1.
- Migration documentation and tests.

Disallowed changes:
- New gameplay features.
- Balance changes.
- Simulation redesign.
- Unrelated rendering refactors.
- Cleanup that is not required by the engine migration.
